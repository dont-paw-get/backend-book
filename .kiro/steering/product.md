# Virtual Shelf 제품 기준

## 제품 한 문장
Virtual Shelf는 책 표지와 인상 깊은 문장을 촬영하면 AI가 서재와 독서 기록을 정리하고, 사용자의 오늘 기분에 맞춰 읽던 책을 추천하는 감성형 독서 관리 서비스다.

## 해결할 문제
- 여러 책을 병렬로 읽을 때 책갈피를 잃거나 마지막 페이지를 잊는다.
- 보유 도서가 많을수록 지금 기분에 어울리는 책을 직접 찾기 어렵다.
- 권수와 시간 중심 기록은 다시 책을 펼치게 만드는 감성적 동기가 부족하다.

## 핵심 사용자 흐름
1. 회원가입 또는 로그인 후 개인 서재 홈에 진입한다.
2. **책 추가**: 표지를 촬영하거나 업로드한다 → OCR/AI가 제목·저자·출판사·무드 후보를 찾는다 → 사용자가 결과와 총 페이지·현재 페이지를 확인/수정한다 → 내 서재에 등록한다.
3. **오늘 읽을 책 찾기**: 오늘의 기분 또는 원하는 무드를 선택한다 → AI가 내 서재의 책만 필터링·정렬한다 → 추천 이유와 함께 현재 읽는 목록을 보여준다 → 사용자가 책을 선택한다.
4. 독서 시작 시 사막여우 캐릭터가 응원 메시지를 제공한다. 사막여우는 따뜻한 독서 동반자이며 판단을 강요하거나 사용자의 감정을 진단하지 않는다.
5. 독서 후 현재 읽은 페이지를 기록한다. 페이지는 이전 위치보다 작게 수정할 수 있지만, 의도된 정정인지 확인한다.
6. 인상 깊은 구절이 있으면 문장을 촬영한다 → OCR 결과를 사용자가 확인/수정한다 → 감상 또는 비밀 메모를 작성한다 → 문장과 감상을 저장한다. 구절 기록은 선택 사항이다.
7. 저장된 진도와 기록은 즉시 개인 서재에 반영한다.

## MVP 우선순위
1. 인증과 사용자별 데이터 격리
2. 표지 촬영 기반 책 후보 인식 및 사용자 확인
3. 내 서재 등록·조회와 현재 페이지 관리
4. 기분 선택과 설명 가능한 책 추천
5. 문장 OCR, 감상/비밀 메모
6. 사막여우 응원 경험

## 제품 원칙
- **확인 가능한 AI**: OCR·책 정보·무드·추천은 후보와 근거를 제시한다. 불확실한 결과를 사실처럼 자동 저장하지 않는다.
- **사용자 최종 결정**: 책 등록, 교정, 추천 선택, 문장 저장은 사용자가 확정한다.
- **내 서재 우선**: 기본 추천 대상은 로그인 사용자가 실제 등록한 책이다.
- **기분은 진단이 아님**: 무드는 사용자가 선택하는 탐색 조건이다. 정신건강 상태를 추론하거나 단정하지 않는다.
- **기록보다 재독서**: 권수 경쟁보다 지금 펼칠 책, 이어 읽을 위치, 기억할 문장을 우선한다.
- **개인정보 기본 보호**: 사진, 감상, 비밀 메모는 기본 비공개다.

## 초기 무드 모델
고정된 감정 진단 대신 확장 가능한 태그를 사용한다. MVP 후보는 `COMFORT`, `CALM`, `ENERGY`, `IMMERSION`, `REFLECTION`, `CURIOSITY`이며 표시 문구는 한국어로 제공한다. 태그 추가·통합은 데이터 마이그레이션과 추천 영향도를 검토한다.

## 성공 기준
- 사용자가 촬영 결과를 교정해 책을 서재에 등록할 수 있다.
- 등록한 책마다 총 페이지와 현재 페이지를 저장하고 이어 읽을 수 있다.
- 기분을 선택하면 내 서재 안에서 추천 이유가 있는 결과를 받는다.
- 독서 후 페이지를 갱신하고, 선택적으로 문장과 감상을 남길 수 있다.
- 한 사용자가 다른 사용자의 서재·사진·감상에 접근할 수 없다.

## 범위 밖
MVP에서는 공개 SNS, 독서 권수 순위, 감정의 의학적 분석, 사용자의 확인 없는 완전 자동 등록, 서재 밖 도서 구매 추천을 기본 기능으로 넣지 않는다.
