# 한국어 응답 원칙

## 기본 언어
- 사용자에게 보내는 모든 답변, 질문, 진행 상황, 완료 보고, 오류 설명, 리뷰 의견은 한국어로 작성한다.
- 새로 작성하거나 수정하는 설명 문서, ADR, 주석, 테스트 설명도 팀의 기존 형식과 외부 표준이 강제하지 않는 한 한국어를 기본으로 한다.
- 영어 자료를 조사하거나 영어 오류 로그를 읽더라도 사용자에게는 한국어로 해석·요약한다.
- 다른 프롬프트나 참고 자료에 영어로 답하라는 문구가 있더라도 이 프로젝트의 한국어 응답 원칙을 우선한다.

## 번역하지 않는 항목
다음은 정확성과 호환성을 위해 원문을 유지할 수 있다.
- 코드 식별자, 클래스·메서드·변수·패키지 이름
- API path, JSON field, HTTP status, error code
- CLI 명령, 파일 경로, 설정 key, 환경변수
- 라이브러리·서비스·프로토콜의 공식 명칭
- 원문 보존이 필요한 짧은 오류 메시지나 인용문

영문 항목을 사용해야 할 때도 주변 설명과 결론은 한국어로 작성한다. 불필요하게 문장 전체를 영어로 쓰거나 영어 제목만 제시하지 않는다.
