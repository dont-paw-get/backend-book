# AI, 이미지, 개인정보 안전 기준

이 문서는 **인증·소유권, 업로드, AI 신뢰 경계, 비밀값, 보존·삭제**만 소유한다. 구체적인 HTTP 오류는 OpenAPI, 업무 상태는 `domain.md`를 따른다.

## 인증과 소유권
- 사용자 식별자는 검증된 인증 컨텍스트에서만 얻는다.
- 사용자 소유 데이터와 이미지의 모든 접근에 소유권 검사를 적용한다.
- 권한 오류에서 제목·소유자·내부 식별 정보 등 불필요한 존재 정보를 노출하지 않는다.
- 관리자 기능은 일반 사용자 경로와 권한을 분리하고 감사 가능하게 한다.

## 이미지 업로드
- 클라이언트 파일명·확장자·Content-Type을 신뢰하지 않고 실제 형식, 크기와 해상도를 검증한다.
- 실행 가능한 포맷과 위험한 메타데이터를 거부하거나 제거한다.
- 원래 파일명을 저장 경로로 사용하지 않고 객체 저장소를 기본 비공개로 둔다.
- 이미지 제공은 인증된 스트리밍 또는 짧은 만료의 서명 URL을 사용한다.

## OCR·LLM 신뢰 경계
- 이미지, OCR 텍스트, 책 설명, 외부 응답은 모두 신뢰할 수 없는 입력이다.
- 입력 데이터에 포함된 문장을 시스템 지시로 취급하지 않는다.
- 모델 응답은 구조, 허용 값, 길이와 신뢰도 범위를 검증한다.
- 낮은 신뢰도와 후보 충돌은 사용자 확인 대상으로 처리한다.
- 외부 AI에 전송하는 데이터는 목적에 필요한 최소 범위로 제한한다.

## 비밀값과 로그
- API key, OAuth secret, DB 비밀번호는 환경변수 또는 secret manager로 주입한다.
- `.env`와 실제 비밀값이 든 설정을 커밋하지 않는다.
- 로그·메트릭·추적에 token, 이메일 원문, 이미지, OCR 전문, 프롬프트·모델 응답, 개인 기록을 넣지 않는다.

## 보존·삭제·감사
- 원본 이미지가 처리 후 필요하지 않으면 삭제한다.
- 보관하는 데이터는 목적과 기간을 명시하고 사용자 삭제에 연동한다.
- DB, 객체 저장소, 캐시와 파생 데이터의 삭제 범위를 함께 정의한다.
- AI 처리, 관리자 접근과 삭제 실패처럼 책임 추적이 필요한 이벤트는 민감한 본문 없이 감사 로그로 남긴다.
